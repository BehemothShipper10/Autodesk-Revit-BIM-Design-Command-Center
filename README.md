- Family libraries for doors, windows, furniture and fixtures
- Shared parameter and schedule configuration guides

- Worksharing and collaboration workflow examples

- Real-world examples demonstrating efficient BIM design workflows

## Requirements

- Windows 10/11
- Installed Autodesk Revit

## Usage

Open the extracted folder and explore the template and family directories. Import the included `.rvt` templates and `.rfa` families directly into Autodesk Revit or follow the documentation to configure shared parameters, schedules, view templates and worksharing. The guides provide practical instructions for each resource.
